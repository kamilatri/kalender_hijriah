# Kalender Hijriah

Aplikasi mobile berbasis Flutter yang menampilkan tanggal Hijriah hari ini dan kalender bulanan beserta padanan tanggal Masehi. Data diambil dari Aladhan API.

## Fitur Utama
- Tanggal Hijriah hari ini
- Kalender bulanan (Hijriah dan Masehi)
- Navigasi bulan sebelumnya/berikutnya
- Penanda hari penting
- Penanganan loading, sukses, dan error (tombol Coba Lagi)

## Teknologi dan Package
- Flutter dan Dart
- Package `http`
- Aladhan API (https://aladhan.com/islamic-calendar-api)

## Cara Menjalankan
1. Pastikan Flutter SDK sudah terpasang.
2. Clone repositori: `git clone https://github.com/kamilatri/kalender_hijriah.git`
3. Masuk ke folder: `cd kalender_hijriah`
4. Install dependensi: `flutter pub get`
5. Jalankan aplikasi: `flutter run`
